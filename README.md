# Odometry Injection

This directory can be shared as a standalone repository.

It reads a ROS 2 bag, checks whether reliable localization already exists, and when needed injects odometry generated by dead reckoning.

## What it does

- Checks whether valid localization is available from `/diagnostics`
- If localization is not reliable, estimates relative motion from IMU yaw rate and vehicle velocity
- Writes a new bag with injected odometry and `/tf`

This is intended for short recordings where relative localization is sufficient, for example around 20 seconds of driving.

## Prerequisites

This tool depends on a ROS 2 Python environment. In addition to standard Python packages, these ROS 2 packages must be available in the sourced environment:

- `rosbag2_py`
- `rclpy`
- `builtin_interfaces`
- `geometry_msgs`
- `nav_msgs`
- `sensor_msgs`
- `tf2_msgs`
- `rosidl_runtime_py`
- `vehicle_msgs`
- `tf_transformations`

Example:

```bash
source /opt/ros/$ROS_DISTRO/setup.bash
```

## Setup

From this directory:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

`pip install -e .` installs the Python entrypoint and the non-ROS Python dependencies declared in `pyproject.toml`.

## Usage

After the ROS 2 environment and virtual environment are active:

```bash
inject-odometry --input /path/to/bag_dir
```

For OXTS-based bags that store velocity in `/sensing/ins/oxts/velocity`:

```bash
inject-odometry \
	--input /path/to/bag.mcap \
	--yaw-rate-topic /sensing/ins/oxts/imu \
	--velocity-topic /sensing/ins/oxts/velocity
```

Or without installation:

```bash
python src/inject_odometry.py --input /path/to/bag_dir
```

Options:

- `-i, --input`: rosbag directory or a single `.mcap` / `.db3` file
- `-o, --output`: output bag directory. Defaults to `<input>_loc`
- `--localization-topic`: odometry topic to write
- `--yaw-rate-topic`: topic used for yaw rate input
- `--velocity-topic`: topic used for velocity input
- `--velocity-ratio`: multiplier applied to velocity input
- `--overwrite`: overwrite output directory if it already exists

## Notes

- If the bag already contains reliable localization, the tool exits without injection.
- If `/diagnostics` conventions change on a new platform, the localization decision logic may need to be updated.
- The generated localization is relative, not globally aligned.
